# Blockside — unofficial Roblox fan portal

A responsive static fan landing page with a clearly disclosed link to https://www.roblox.com/login. Not affiliated with Roblox Corporation. There is no login form, credential collection, account integration, JavaScript, analytics, or backend.

## Edit
Update `index.html`, which includes the styles. No build tools or dependencies are required.

## Publish
GitHub Pages serves `main` from the repository root.

Live URL: https://jamierlj09-debug.github.io/roblox-fan-portal/

Only the official Roblox website or app should receive Roblox credentials. Do not add password collection to this fan page.
